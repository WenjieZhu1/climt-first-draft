# Simple Home Cooking

This is my first draft for the client website project in CS class.

My client is a family member who likes cooking. This website shares a few easy recipes.

## Pages
- Home (`index.html`)
- Recipes (`recipes.html`)
- About (`about.html`)

I used HTML, CSS, and Bootstrap for the navbar and layout.

## GitHub Pages
1. Upload these files to a public GitHub repository.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the **main** branch and **/(root)**, then save.

My website link will be available after GitHub Pages finishes publishing.
